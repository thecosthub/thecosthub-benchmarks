# Security Policy

## Reporting Security Vulnerabilities

We take the security and integrity of TheCostHub and our verified benchmark telemetry seriously. If you believe you have discovered a vulnerability, data integrity issue, or security flaw, please let us know immediately.

### How to Report

Please **do not** report security vulnerabilities through public GitHub issues or discussions.

Instead, please report security issues via email to:
**security@thecosthub.com**

Please include:
1. Description of the issue and potential impact.
2. Step-by-step instructions or proof-of-concept to reproduce.
3. Relevant task YAML or pipeline configurations.

### Response Time

- **Acknowledgment**: Within 24 hours.
- **Assessment & Status Updates**: Within 72 hours.
- **Resolution**: High-priority patches are deployed within 7 business days.

## Data Integrity Guarantees

All benchmark numbers published on the TheCostHub leaderboard are deterministically verified via automated CI pipelines. Any manipulation or fraudulent data submissions will be investigated and permanently rejected.
